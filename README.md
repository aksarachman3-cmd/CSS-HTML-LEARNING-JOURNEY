## 📖 Daily Highlights

### Day 1 — Foundation
- **HTML Basics:** buttons, paragraphs, links, images, and nested structure.
- **CSS Basics:** styling with `color`, `background-color`, `border`, `border-radius`.
- **Hover, Transition & Shadow:** interactive buttons with `:hover`, `transition`, and `box-shadow`.
- **DevTools & CSS Box Model:** inspecting elements, `margin`, `padding`, and the box model.
- **Text Style:** `font-weight`, `font-size`, `line-height`, and text colors.

### Day 2 — Layout & Structure
- **Text Style (continuation):** `font-family` (Tahoma, Arial, Montserrat, Roboto), `text-align`, `vertical-align`, and underline via `<span>`.
- **HTML Structure:** clean document skeleton with proper `<head>`/`<body>` and external CSS linking.
- **Images & Text-Box:** combining `<img>` with text inputs and solid layouts.
- **Display Property:** the three element types — **block**, **inline-block**, and **inline** (`p`, `img`/`input`/`button`, `strong`/`span`).
- **The `<div>` Element:** grouping content into reusable containers, culminating in a multi-preview **YouTube layout** using `thumbnail → title → author → stats`.

## 🛠️ How to Use

1. **Clone** the repository:
   ```bash
   git clone https://github.com/aksarachman3-cmd/CSS-HTML-LEARNING-JOURNEY.git
   ```
2. **Open** any exercise file (*e.g.* `"DAY 2/8. Display Property/youtube.html"`) in your browser.
3. **Edit along:** every file is a self-contained exercise with comments explaining the key concept.

> 💡 **Tip:** Files with external stylesheets (`.css`) use Google Fonts, so an internet connection is required for the custom fonts to load.
